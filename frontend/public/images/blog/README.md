# 博客默认封面

三张封面通过 OpenAI 内置 ImageGen 独立生成，随后转换为质量 82 的 JPEG；没有使用参考站的图片或源码。运行时优先展示文章自身封面，缺失或加载失败时按标题、路径与标签选择以下图片。

- `architecture.jpg`：工程、技术与模块主题。提示词：横向编辑摄影，蓝色玻璃与混凝土构成的模块建筑，干净的几何构图，天空与自然光，安静而现代，无文字、标志、水印或人物。
- `writing.jpg`：写作主题。提示词：横向编辑摄影，温暖日光下的安静写作桌面，纸张、笔记与书籍，自然材质，克制的杂志构图，无可辨识文字、标志或水印。
- `forest.jpg`：其他主题。提示词：横向编辑摄影，深绿色森林与平静湖面，自然日光、轻雾与丰富但克制的绿色，宁静的旅行杂志构图，无文字、标志或水印。

生成工具：`image_gen.imagegen`，默认内置模式。前端选择逻辑：`src/features/blog/BlogDirectory.tsx` 的 `fallbackCover`。
